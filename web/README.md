# Oceanic-OS Web Prototype

This directory contains a minimal frontend for the Oceanic-OS full-stack prototype.

## Run the prototype

1. Start the backend API:
   `uvicorn oceanic_os.api:app --reload`
2. Open `web/index.html` in your browser.
3. Click `Refresh dashboard` to load current state from the API.

> The frontend is intentionally small and static so the system stays easy to inspect.
