# Oceanic-OS Web Prototype

This directory contains the static frontend for the Oceanic-OS full-stack prototype.

## Run the prototype

1. Start the backend API:
   `uvicorn oceanic_os.api:app --reload`
2. Open the browser at:
   `http://127.0.0.1:8000/`
3. Use the page to view dashboard state, identities, and create a new identity.

> The frontend is intentionally small and static so the system stays easy to inspect.
