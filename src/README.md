# src

This directory contains initial module scaffolding for the Oceanic-OS project.

Each subfolder is a placeholder for the first experiments and documentation on the current focus areas.

## Current modules

- `identity/` — identity and authentication design.
- `memory/` — memory, context, and persistent state.
- `dashboard/` — observability and experience surfaces.
- `agents/` — agent architecture and orchestration.
- `knowledge/` — knowledge graphs, models, and shared understanding.
- `automation/` — workflow automation and safe action loops.
- `ecosystem/` — integration, collaboration, and platform growth.
- `stewardship/` — governance, trust, and long-term care.
- `protocol/` — core conventions and operating principles.

## Next steps
