# Roadmap

Oceanic-OS is organized by horizon and focus. Each horizon is a set of living goals, not a fixed deadline.

## Seed

Begin with mission clarity and a minimum viable structure.

- Capture the core philosophy.
- Create a durable project scaffold.
- Identify the first experiments.

## Today

Build the foundations for agency in the present moment.

- Identity: persistent and human-centered identifiers.
- Memory: reliable context storage and retrieval.
- Dashboard: a clear lens into state, actions, and health.

## This year

Grow the system with active capabilities.

- Agents: composable actor models and orchestration.
- Knowledge: shared models, documentation, and contextual intelligence.
- Automation: safe, observable workflows that support humans.

## This decade

Expand into a broader ecosystem.

- Ecosystem: interoperable tools, partners, and shared infrastructure.

## Lifetime

Steward the system across change.

- Stewardship: long-term governance, preservation, and community care.
