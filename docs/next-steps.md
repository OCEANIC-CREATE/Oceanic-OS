# Next Steps

1. Define a small first experiment.
2. Document the current assumptions.
3. Build the first working prototype in one module.
4. Review the prototype with the mission principles.
5. Iterate in small, measurable increments.

## Recommended first experiments

- Identity: proof of concept for a human-centric identity model.
- Memory: a simple store for contextual notes and retrieval.
- Dashboard: a lightweight status page or CLI status summary.

## How to use this repo

- Keep the mission documents as the first source of truth.
- Add design notes to the relevant module folder.
- Make every commit small, descriptive, and reviewable.
